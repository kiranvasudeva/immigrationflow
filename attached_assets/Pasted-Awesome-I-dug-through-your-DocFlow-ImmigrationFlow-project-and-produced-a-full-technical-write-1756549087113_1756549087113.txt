### Prompt A — Harden i18n end-to-end

### Prompt B — RBAC & tenant guards

“Create `server/middleware/rbac.ts` with:

* `requireRole(...roles)` and
* `requireOwnership(resourceType)` for company/worker scoping.
  Apply to **all** routes in `server/routes` so that ADMIN can see all, OWNER limited to their client(s), WORKER only their own assignments/documents.
  Add negative tests in `tests/api.rbac.test.ts`.”

### Prompt C — CRUD + OpenAPI

* Install `swagger-ui-express` and `zod-to-openapi`, generate an **OpenAPI** doc and serve it at `/docs`.
